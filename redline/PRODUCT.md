# Redline
A personal performance-car reference dashboard. Enthusiasts select manufacturer, model, trim and model year, compare performance, inspect engine data and understand depreciation. Cover 2018–2024 inclusive as explicitly requested, US specification with USD prices and imperial units. Include BMW M Performance and M, Mercedes-AMG 63, Lamborghini, Bugatti, McLaren, Ferrari and Porsche 911. Dark, conventional dashboard requested; no questions requested. Use public EPA API data and manufacturer references, honest missing data, calculated curves clearly distinguished from measured dyno runs. A static site; no secrets in browser assets. Market valuations require an authenticated provider and must not be invented. Device-local comparison and selection preferences only.
